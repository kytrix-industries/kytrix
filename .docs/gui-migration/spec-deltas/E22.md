## 1. 能力范围

- **双轴滚动容器**：`ScrollAxes { Vertical, Horizontal, Both }`、`ScrollConfig { axes, line_height }`、`ScrollState { offset, content, viewport, axes }`；`max_offset`/`clamp_offset` 仅启用轴计算，未启用轴恒 0。
- **虚拟列表横向内容宽**：`VirtualListConfig.content_width: Option<LogicalPx>`；`Some` ⇒ `ScrollSlot.axes = Both`、内容宽 = w；`None` 保持单轴纵向（`VirtualListConfig` 因 `Option` 非 `Copy`）。
- **Table 横向滚动**：内容宽 = Σ `column_contribution`（Fixed 宽 + Flex `min_width`）；`ColumnWidth::Flex { weight, min_width }`、`Column::flex(header, weight, min_width: LogicalPx)` 三参数、无默认/无链式；`TableOptions` 不新增开关（横向全局默认）。
- **零宽回退**：`content_width == 0`（全部 Flex 且 `min_width` 均为 0）时**不启用横向**——内层 List `content_width = None`、`axes = Vertical`、行宽 = viewport、`max_x = 0`、不建/不显示 hbar（旧纯纵向布局兼容）；`content_width > 0` 才传 `Some`/`Both`。新增零宽回退用例覆盖。
- **Table sticky 表头**：`header`（背景/裁剪，y 固定）→ `header_content`（`content_width > 0` 时 absolute；`Table::sync` 写 `left=-List.offset.x`、`width=max(content_width, viewport.width)`；零宽回退时 header 保持普通流 `width_full`，避免自动宽父链把表宽压到 0）；水平偏移唯一真源 = 表体 List `ScrollSlot.offset.x`；resize 宽→窄由 kit 侧 `scroll_to` 夹回（一帧瞬态）。
- **滚动条**：Table 自管垂直/水平两条 `ScrollBar`；track 代理到 List viewport；局部 rail 尾隙（垂直条底 4 px、水平条右 4 px，不重叠）；`ScrollbarAxis::point` 保留另一轴。
- **a11y**：双轴 `A11yScroll` 用 `orientation: Option`（Both ⇒ `None`），动作步长按轴（横向 width、纵向 height、Item line_height）；`a11y_scroll_target(tree, node, axis: Option<ScrollAxes>)` 按动作轴过滤（P4）。
- **路由/闩锁**：`scroll_candidates` 代理链 + visible/interactive 过滤 + `visited`/`MAX_CHAIN_HOPS`；`ScrollSession`（`SCROLL_SEQUENCE_IDLE=200ms`）；45° 投影只影响 `consumed` 记账（偏移不变）；程序化与滚轮统一立即 `scroll_to`（滚动动画 API 已删除）。
