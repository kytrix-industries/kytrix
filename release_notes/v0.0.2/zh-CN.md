# Kytrix v0.0.2

## 新增

**数据时间时区**

行情数据一律以 UTC 发布，在此之前它也只能以 UTC 显示。Kytrix 新增了 **数据时间时区**设置：在 UTC−12 到 UTC+14
之间任选一个整点时区，所有数据时间都会换算成该时区后再显示。

该选项位于「设置 → 通用设置 → 数据时间时区」，作用于全局——K 线的时间轴与十字光标、市场成交、强平订单流、新闻、推文监控、钱包监控，以及持仓量、多空账户比、主动买卖量等图表。

切换后立即生效，已经显示在屏幕上的数据同步重算，无需重启。该选择与其他设置一同保存；默认值为 UTC+0，也就是本版本之前的显示方式。

**在浏览器中打开账户**

已登录时，头像下拉菜单在「退出登录」上方新增「 **账号**
」项。它会在系统默认浏览器中打开你的账户控制台，并以同一个账户自动登录。

## 变更

**设置导航**

「外观」不再是设置树顶部一条单独的条目。显示相关设置现在归入「 **通用设置**」分组——外观与新增的数据时间时区并列，位于列表首位。「
**市场参与者**」分组在设置打开时默认展开，各场所的凭据无需多点一次即可看到。
